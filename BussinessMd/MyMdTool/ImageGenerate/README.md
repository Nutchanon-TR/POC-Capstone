# คู่มือสร้าง asset และแมป

ชุด MD สำหรับงาน reference → asset/character → base map → แก้ใน tool → export ไปใช้ในเกม

MD เป็นข้อกำหนดและขั้นตอน ผู้ทำงานหรือ AI ต้องอ่านไฟล์ที่เกี่ยวข้องแล้วใช้เครื่องมือสร้างภาพ เตรียมไฟล์ ประกอบแมป และตรวจผล คู่มือชุดนี้ยังไม่ได้เพิ่มโปรแกรมสร้างแมปหรือเปลี่ยนโค้ด Editor

## เลือกไฟล์ตามงาน

| ไฟล์ | ใช้เมื่อ |
|---|---|
| [ReferenceImageGuide.md](ReferenceImageGuide.md) | กำหนดบทบาท reference, design lock, สไตล์ และ prompt กลาง |
| [MapStandard.md](MapStandard.md) | เลือก/กรอก profile ของโปรเจกต์ให้ทุกงานใช้กติกาเดียวกัน |
| [ObjectAssetGuide.md](ObjectAssetGuide.md) | สร้างสิ่งของ พื้น ผนัง หรือบูธหลายชิ้น |
| [CharacterAssetGuide.md](CharacterAssetGuide.md) | สร้างตัวละคร มุมต่าง ๆ และชุด animation |
| [BlueprintToMapGuide.md](BlueprintToMapGuide.md) | อ่าน blueprint และประกอบเอกสารแมปที่แก้ต่อได้ |

ReferenceImageGuide.md เปลี่ยนชื่อและปรับจาก ImageGenerateWithReference.md เดิม โดยเก็บ reference roles, โมดูลสไตล์ และการแก้เฉพาะจุด ส่วนรายละเอียดสิ่งของ/ตัวละครย้ายไปคู่มือเฉพาะ
