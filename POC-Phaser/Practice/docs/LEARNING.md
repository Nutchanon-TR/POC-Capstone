# แนวทางฝึก

## เป้าหมาย

เขียนเกมเดินสำรวจแผนที่งานจาก assets ที่มีอยู่ โดยอธิบายการทำงานตั้งแต่ React เปิดพื้นที่ให้ Phaser
จนถึงการอ่านตำแหน่งจาก Tiled การแสดงรูป การเคลื่อนที่ และการชน
โฟลเดอร์นี้เริ่มที่บท 0 และยังไม่มีเฉลยเกมติดมา

## ข้อตกลงในการสอน

1. ให้โค้ดทีละส่วนที่รันได้ เป้าหมายหนึ่งอย่างต่อรอบ
2. บอกไฟล์ที่จะสร้างหรือแก้ ระบุว่าแทนทั้งไฟล์หรือเพิ่มตรงไหนให้ชัดเจน
3. ก่อนโค้ด บอกว่ากำลังแก้ปัญหาอะไร และผลรอบนี้จะเห็นอะไร
4. หลังโค้ด ไล่ลำดับการทำงาน และอธิบายศัพท์หรือ syntax ใหม่ เช่น import, class, this, useRef, useEffect
5. ถ้าใช้ library ให้บอกว่า library นั้นรับผิดชอบอะไร และทำไมต้องใช้ตรงนี้
6. ให้รันดูผล พร้อมจุดตรวจที่สังเกตได้จริง แล้วทดลองเปลี่ยนค่าทีละค่า
7. รอผลจากผู้เรียนก่อนให้ส่วนถัดไป ถ้า error ให้แก้รอบนี้ก่อน
8. ไม่เขียนโค้ดบทเรียนลงไฟล์แทนผู้เรียน เว้นแต่เขาขอให้ทำ
9. ตอนอ่าน TMJ/TSJ ให้เปิดข้อมูลจริงควบคู่กับโค้ด และตามค่าตั้งแต่ต้นทางจนถึงภาพบนจอ
10. ค่อยแยก module เมื่อเห็นแล้วว่าโค้ดส่วนนั้นทำอะไร ไม่เริ่มด้วยระบบสำเร็จรูปหลายชั้น

## ลำดับฝึก

| ช่วง | เพิ่มอะไร | ผลที่เห็นและเรื่องที่อธิบาย |
| --- | --- | --- |
| 0 | Next.js และ assets | หน้าเว็บเปิดได้ โค้ดปัจจุบันเป็น React/HTML |
| 1 | ต่อ Phaser กับ GameHost | canvas สีพื้นหนึ่งอัน เริ่มจาก DOM ref แล้วต่อ useEffect, async import และ cleanup |
| 2 | Scene แรก | ข้อความและรูปทรงที่ตำแหน่งกำหนดเอง รู้จัก constructor, preload, create, update และ this |
| 3 | โหลดรูปหนึ่งไฟล์ | แสดงโต๊ะจาก props/table-long-v.png แยก URL, texture key, พิกัด และ origin |
| 4 | อ่าน TMJ และ TSJ | โหลด JSON ตรวจรูปแบบข้อมูล แล้วตรวจค่าใน console ยังไม่วาดทั้งแผนที่ |
| 5 | ผูกรหัสกับรูป | ตาม gid → firstgid → local id → TSJ image → texture key แล้ววาดวัตถุหนึ่งชิ้น |
| 6 | วาดพื้นและเฟอร์นิเจอร์ | แปลง index ของ Floor เป็น column/row และอ่าน x/y จาก object layer |
| 7 | ตัวละครและจุดเกิด | เริ่มด้วยรูปทรงที่ Spawn_Player แล้วค่อยเปลี่ยนเป็น sprite และ animation |
| 8 | ปุ่มและความเร็ว | เดินได้ รู้จัก update, velocity, delta, normalize และหน่วยพิกเซลต่อวินาที |
| 9 | Physics และพื้นที่ชน | แสดง debug hitbox อ่าน Collision ของแผนที่และ objectgroup ของรูป แล้วเชื่อม collider |
| 10 | กล้องและลำดับภาพ | กล้องตามผู้เล่น world bounds กับ camera bounds และการยืนหน้า/หลังเฟอร์นิเจอร์ |
| 11 | ปฏิสัมพันธ์กับหน้าเว็บ | เข้าเขตบูธ กด E แล้วแสดงข้อมูลใน React ค่อยแยก Scene/Player/loader ตามหน้าที่ |

แต่ละแถวอาจแบ่งหลายรอบ เช่น บทอ่าน JSON แบ่งเป็นโหลด TMJ ก่อน ตามด้วย TSJ
ไม่ต้องให้โค้ดทั้งบทพร้อมกัน ลำดับ animation/physics ปรับได้ตามความเข้าใจผู้เรียน

## เกริ่นก่อนโค้ดส่วนแรก

Next.js จัดหน้าเว็บให้เรา React สร้าง `<div>` ที่เป็นพื้นที่ทดลอง
Phaser จะสร้าง `<canvas>` ภายใน div นั้นเมื่อหน้าเว็บพร้อมใช้งานในเบราว์เซอร์
TypeScript ช่วยตรวจข้อมูลที่ส่งระหว่างส่วนเหล่านี้ ส่วนรูปและไฟล์ JSON อยู่ใน public

```text
Next.js เปิดหน้า /
  → page.tsx วาง GameHost
  → GameHost มี div สำหรับเกม
  → [บทที่ 1] เมื่อ React mount จึงสร้าง Phaser.Game
  → Phaser สร้าง canvas และเริ่ม Scene
```

บทแรกจะทำให้เห็น canvas สีพื้นก่อน ยังไม่โหลดแผนที่
เราต้องเข้าใจก่อนว่าใครสร้างเกม สร้างเมื่อไร และลบทิ้งเมื่อไร
เพราะ Next.js มีทั้งการทำงานฝั่ง server และ browser และโหมดพัฒนาของ React อาจ setup/cleanup ซ้ำ

Client Component ยังอาจถูก prerender ฝั่ง server จึงไม่ควร import Phaser เป็น runtime ที่ระดับบนสุดโดยไม่จัดขอบเขต
บทแรกจะค่อยอธิบายการ import หลัง mount รวมถึงป้องกัน async import สร้างเกมหลัง unmount
ทุกครั้งที่ทดลองแก้ไฟล์ต้องเหลือ canvas เดียว และ cleanup ต้อง destroy เกมเก่า

## เชื่อมไฟล์ข้อมูลกับภาพที่จะเห็น

```text
expo.tmj          ตำแหน่ง, layer, gid, จุดเกิด, เขตพื้นที่
  → tilesets[0].source = expo.tsj
expo.tsj          local id, path รูป, ขนาดรูป, พื้นที่ชนของรูป
  → props/*.png หรือ structure/*.png
Phaser loader     โหลดไฟล์และเก็บ texture ตาม key
Scene             เลือกรูปแล้ววางในพิกัดโลก
Camera            เลือกส่วนของโลกที่จะเห็นบน canvas
```

ลูกศรนี้เป็นลำดับที่เราจะเขียนเอง Phaser ไม่ได้ตาม external TSJ หรือ properties เฉพาะโปรเจกต์ให้ครบอัตโนมัติ
แผนที่ชุดนี้เป็น image collection มีรูปคนละขนาดและมีสัญญาพิกัดเฉพาะ
เราจะอ่านจริงก่อนเลือกใช้ Tilemap API หรือวาดจากข้อมูลที่แปลงแล้ว และอธิบายส่วนที่เราเขียนเสริมให้ชัด
