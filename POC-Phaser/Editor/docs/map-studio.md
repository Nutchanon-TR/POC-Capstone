# Map Studio รุ่นแรก

## ขั้นตอนใช้งาน

1. เปิด `/editor` เลือก **Blueprint / ขนาดแมป** ตั้งชื่อ จำนวนช่องแนวนอน/แนวตั้ง และพื้นเริ่มต้น เลือก **เริ่มแมปใหม่** เมื่อต้องการเริ่มจากพื้นที่ว่าง หรือ **ปรับขนาดแมปปัจจุบัน** เมื่อต้องการเก็บงานเดิม
2. อัปโหลด blueprint ปรับความทึบและตำแหน่งให้เป็นแนวอ้างอิง ความกว้างและความสูงเปลี่ยนตามอัตราส่วนเดิม สามารถซ่อนภาพได้โดยไม่ลบ
3. เลือกภาพในคลัง หรือกด **เพิ่ม asset PNG** เพื่อเพิ่มภาพของตัวเอง ตั้งขนาดแสดง กรอบชน และแนวหน้าหลังก่อนเพิ่มในคลัง
4. คลิกบนแมปเพื่อวาง ใช้ Grid/Snap สำหรับจัดตำแหน่ง Inspector ล็อกสัดส่วนโดยค่าเริ่มต้น และมีปุ่มคืนขนาดมาตรฐาน
5. กำหนดจุดเกิด ลากกรอบชนหรือพื้นที่ Zone ตามต้องการ เปิดมุมมองกรอบชนเพื่อตรวจ footprint
6. ทดลองเดินในฉบับร่าง แล้วกดบันทึกเมื่อต้องการเปลี่ยนแมปที่ Hall ใช้
7. Export ZIP เพื่อรับ `exhibition.tmj`, `tilesets/exhibition.tsj` และ `pieces/*.png` ครบ เปิดต่อใน Tiled ได้

## ทดลองเดินและขนาดบล็อก

ปุ่มรูป Student02 ทรงกลมที่มุมล่างซ้ายใช้เปิด/ปิดตัวละครทดลองเดิน ควบคุมด้วย WASD หรือลูกศร บนมือถือมีปุ่มทิศทาง กล้องตามตัวละครระหว่างเดินและกลับมาพอดีแมปเมื่อปิด ตัวละครชนกรอบชนและขอบแมป โดยใช้กรอบเท้า 26 × 12 px เลือกจุดเกิดที่วางไว้ก่อน หากจุดนั้นชนสิ่งกีดขวางจะหาพื้นที่ว่างให้

ตัวละครทดลองไม่ถูกเพิ่มในเอกสารแมปหรือ Export และออกจากโหมดเมื่อสลับแมป ปุ่ม **ขนาดบล็อก** มี อิสระ / 8 px / 16 px / 32 px อิสระใช้กับตำแหน่งสิ่งของและกรอบสี่เหลี่ยม ส่วน Floor ยังอ้างช่องของ TMJ เพื่อให้ภาพตัวอย่างกับพื้นจริงตรงกัน ตัวเลือกนี้ไม่เปลี่ยน tile size ของไฟล์แมปเดิม

## ปรับลำดับภาพที่ซ้อนกัน

เลือก asset แล้วเปิด **รายละเอียด** ใช้ **หน้าสุด / หลังสุด / ขึ้น 1 ระดับ / ลง 1 ระดับ** เพื่อปรับภาพที่เลือก ถ้าภาพถูกบัง ให้เลือกชื่อจาก **เลือกวัตถุในแมป** กลุ่มบูธจะขยับลำดับพร้อมกันและรักษาลำดับของชิ้นส่วนภายใน พื้นยังคงอยู่ใต้สิ่งของ

Ctrl+Z ย้อนกลับได้ ลำดับที่กำหนดเองติดไปกับ Save และ Export ใน custom property `renderDepth` ของ TMJ โปรเจกต์ที่นำไปใช้ต้องอ่านค่านี้ตอนกำหนด Phaser depth เมื่ออยากกลับไปเรียงตามตำแหน่ง Y ให้กด **เรียงตามตำแหน่งอัตโนมัติ**

## ข้อมูลหลักและภาพ

- เอกสารแมปหลักยังเป็นโครงสร้าง Tiled TMJ เก็บ JSONB ใน `maps.document` การแก้ภาพอ้างอิง/พื้นที่/สิ่งของรวมอยู่ในประวัติ Undo/Redo และ revision เดียวกัน ไม่มี `map.json` อีกชุดสำหรับแก้ไข
- Blueprint ฝังเป็น data URL ใน string custom property `studio.blueprint` ซึ่งเก็บชื่อ ขนาดต้นฉบับ ตำแหน่ง ขนาดแสดง ความทึบ และสถานะแสดงภาพไว้ด้วย compiler ไม่ใช้ property นี้สร้างฉากเกม
- ภาพชุดเดิมและ TSJ ต้นฉบับไม่ถูกเขียนทับ ภาพใหม่เก็บในตาราง `editor_assets` เป็น PNG bytea พร้อมนิยามขนาด/footprint Asset ID และ GID คงที่เมื่อเปิดใหม่
- การเพิ่มภาพในคลังบันทึกทันที แยกจากการกดบันทึกแมป Undo/Redo ของแมปไม่ลบภาพออกจากคลัง การนำเข้าภาพเดิมด้วยชื่อและนิยามเดียวกันไม่สร้าง asset ซ้ำ
- Backend ตรวจชนิดภาพจริง ขนาด จำนวนพิกเซล และกรอบชนก่อนเก็บ ส่งภาพผ่าน image endpoint ที่ใช้ ID ไม่อ่าน path จากผู้ใช้
- Runtime โหลดเฉพาะ texture ที่เอกสารแมปใช้งาน ส่วน Editor โหลดคลังสำหรับวางภาพเพิ่มเติม ZIP มีนิยามและภาพทั้งหมดในคลังเพื่อให้เลือกเพิ่มใน Tiled ได้

## กติกาของภาพและการวาง

- Asset ใช้ PNG ภาพนิ่ง สูง/กว้างไม่เกิน 2048 px ไฟล์ไม่เกิน 2 MB ขนาดแสดงคำนวณจากความกว้างและอัตราส่วนต้นฉบับ
- Floor สำหรับระบายเป็น PNG 32 × 32 และไม่มีกรอบชน
- กรอบชนใช้พิกัดภายในภาพต้นฉบับ และปรับสเกลตาม instance เหมือนภาพ แนว `depthY` อ้างขอบบนของภาพ
- Instance สามารถปิดกรอบชนผ่าน property `collisionEnabled=false` และปรับ `depthY` ได้ โดยไม่แก้นิยามต้นฉบับของภาพ
- Collider เป็นสี่เหลี่ยมที่ขวางผู้เล่น Zone เป็นสี่เหลี่ยมพร้อมชื่อที่บอกบริเวณ กรอบชนไม่ทำให้สิ่งของ interact ได้อัตโนมัติ
- ปรับขนาดแมปแล้วพื้นเดิมในส่วนที่ยังอยู่จะคงเดิม พื้นส่วนเพิ่มใช้แบบที่เลือก ขอบกำแพงของแมปตั้งต้นตามขนาดโลก แต่ไม่ย้ายสิ่งของ/NPC/spawn ให้เอง หากลดขนาดแล้วมีสิ่งใดอยู่นอกแมปจะปฏิเสธการแก้ไข
- ใช้ขอบกรอบหรือ Inspector เลือก Zone/Collider เพื่อไม่ให้พื้นที่โปร่งใสรับคลิกทับสิ่งของภายใน

## ขอบเขตของรุ่นนี้

- Blueprint เป็นภาพอ้างอิงสำหรับวางแมป ยังไม่มี AI อ่านภาพแล้ววางอัตโนมัติหรือสร้างภาพใหม่
- อัปโหลดภาพสิ่งของ/โครงสร้าง/พื้นได้ ตัวละครยังใช้ Kaguya และ InternWitch เดิม ยังไม่มี import spritesheet หรือเครื่องมือจัดเฟรมตัวละคร
- TMJ import ใช้ GID ที่มีในคลังของฐานข้อมูลนี้ ZIP ส่งต่อให้ Tiled ได้ แต่ยังไม่มี ZIP import สำหรับนำภาพ/TSJ จากฐานข้อมูลอีกเครื่องกลับเข้ามา
- ไม่มีการแก้นิยาม footprint ของ asset หลังอัปโหลดผ่าน UI สามารถเพิ่มแบบใหม่ ปิด collision ของ instance หรือวาง Collider แยกได้
- ยังเป็น POC บน localhost ไม่มีระบบบัญชี สิทธิ์อัปโหลด หรือร่วมแก้แมปหลายคน
