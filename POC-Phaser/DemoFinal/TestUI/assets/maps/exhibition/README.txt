Open map.tmj in Tiled. Keep tilesets/ and images/ beside it. This finite orthogonal map uses square 16, 32, 64 or 128px tiles and an image collection tileset. Floor PNGs match the map tile size. No API, database, or character runtime is required.

Interaction data: TSJ tile properties interactable (bool) and interactKind (string) provide defaults. TMJ object properties interactEnabled (bool), interactKind, interactAction (string), interactX/Y/Width/Height (numbers) override defaults per placed asset. The interaction label is the object name (legacy label/title properties are also supported). Bounds are in native image pixels: worldX = layerOffsetX + object.x + interactX * object.width / imagewidth; equivalent for Y. Width/height scale with the placed sprite; omitted bounds cover the full image. interactEnabled=false removes only the interaction frame, keeping the sprite. Do not infer gameplay behavior from these keys; the consuming project supplies its own actions. studio/prefabs.json preserves depthY for separate props placed on cloth tables.
