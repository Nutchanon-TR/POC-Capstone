# Neon Thread

เกมต้นแบบโหนใยตามตึกในเมือง Cyberpunk ด้วย Three.js + Vite ใช้โมเดลและเมืองที่สร้างด้วยโค้ด

## เปิดเล่น

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง (ปกติ http://localhost:5173) แล้วกด **เข้าสู่เมือง**

- WASD: เดิน / ควบคุมแรงเหวี่ยงกลางอากาศ
- เมาส์: หันกล้อง (ถ้าล็อกเมาส์ไม่ได้ ให้เลื่อนไปทางขอบจอ)
- เมาส์ซ้ายหรือ E ค้าง: ยิงใยเกาะจุดที่ช่วยเล็งไว้บนตึก ระยะสูงสุด 110 เมตร
- ปล่อยเมาส์ / E: ปล่อยใย รักษาแรงส่ง
- Space: กระโดดจากพื้นหรือดาดฟ้า
- Shift ค้างใกล้ผนัง: เกาะตึก แล้ว W/S วิ่งขึ้น–ลง, A/D ไต่ด้านข้าง ปล่อย Shift เพื่อปล่อยตัว
- Space ขณะไต่: กระโดดถีบออกจากผนัง (มีช่วงหน่วงก่อนเกาะใหม่)
- R: กลับ checkpoint ล่าสุด โดยเวลาไม่รีเซ็ต
- Esc: พักเกม

โหนผ่านวงแหวนสีเขียวทั้ง 8 วงตามลำดับ แต่ละวงบันทึก checkpoint ให้อัตโนมัติ จบแล้วเล่นใหม่เพื่อทำเวลาได้

## ตรวจสอบ

```sh
npm test
npm run build
```

`src/main.js` จัดการฉาก แสง กล้อง อินพุต และภารกิจ ส่วน `src/physics.js` จัดการข้อจำกัดเชือก การชน การไต่ตึก/ขึ้นดาดฟ้า และการผ่านวงแหวน ใช้ฟิสิกส์ 120 steps/second และ bloom หลังเรนเดอร์

`src/character.js` สร้างโมเดล Spider-Man ชุดแดง–น้ำเงิน มีลายใย ตาขาว ตราแมงมุม และข้อต่อไหล่ ศอก สะโพก เข่า อนิเมชันแบบ procedural ผสมท่า idle/run/jump/fall/swing/wall-run ตามฟิสิกส์จริง เส้นใยเริ่มจากมือที่เล็งเข้าหาจุดเกาะ เมื่อไต่ถึงขอบตึกจะขึ้นดาดฟ้าอัตโนมัติ โหมด reduced motion ลดการแกว่งแขนขาซ้ำ ๆ และการเด้งตัว แต่ยังแสดงท่าทางตามสถานะ

เหมาะกับเบราว์เซอร์เดสก์ท็อปที่รองรับ WebGL2 ต้องใช้คีย์บอร์ดและเมาส์ ยังไม่มี touch controls หรือระบบต่อสู้ รูปแบบตัวละครเป็นโมเดลเรียบง่าย ฟอนต์ Google Fonts ใช้อินเทอร์เน็ต มี fallback หากโหลดไม่ได้
